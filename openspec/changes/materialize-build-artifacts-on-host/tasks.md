# Implementation Contract

Every checkbox below is required for completion. A phase is complete only when all of its RED → GREEN → INTROSPECT → VALIDATE tasks pass and every listed deliverable exists. GREEN work SHALL be limited to satisfying that phase's RED tests and SHALL NOT implement behavior owned by a later phase. Newly discovered scope SHALL be added to this contract before implementation.

A phase MAY depend only on phases with lower numbers that appear in its `Depends on` line. Work in independent branches of the DAG MAY proceed in parallel, but the canonical-project-wide build lock in external project state SHALL serialize side-effecting build acceptance runs.

External prerequisite: change `add-locked-npm-environment-assembler` SHALL be completed before Phase 6 begins.

Phase dependency DAG:

```text
Phase 1 ──> Phase 2 ──> Phase 3 ──> Phase 4 ──┬──> Phase 5 ──┐
                                              └──> Phase 6 ──┴──> Phase 7
```

**Revision note:** This change was revised after implementation had already begun. The revision reopened and expanded some earlier-phase requirements while retaining implementation and tests that had already been completed for later phases. Retained later-phase work is not evidence that the revised dependency DAG has been satisfied: every affected later-phase task SHALL be revalidated after its newly reopened dependencies are complete, and its checkbox SHALL represent the revised contract rather than only the earlier implementation pass.
