# Implementation Binding Contract

Every checkbox in this document is required for completion. A phase is complete only when all of its RED → GREEN → INTROSPECT → VALIDATE tasks pass and every listed deliverable exists. GREEN work SHALL be limited to satisfying that phase's RED tests and SHALL NOT implement behavior owned by a later phase. Newly discovered scope SHALL be added to the planning artifacts before implementation.

Phase dependency DAG:

```text
Phase 1 ──> Phase 2 ──> Phase 3 ──> Phase 4 ──> Phase 5 ──> Phase 6
```

A phase MAY depend only on phases with lower numbers listed in its `Depends on` field. Later-phase tests or retained implementation are not evidence that an earlier dependency is complete.
